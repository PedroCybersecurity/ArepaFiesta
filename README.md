# Mi arepita 🫓❤️

**by papa Pedro con cariño**

Juego familiar de arepas venezolanas con **20 recetas**, **54 ingredientes**, **Arepa Loca de tu familia** personalizable y colección local.

### Novedades

- Voz guía en español durante toda la partida: recetas, ingredientes, pistas, errores y celebraciones.
- Música instrumental original suave inspirada en el joropo venezolano. No utiliza canciones comerciales.
- Botón **🎶 ¡Empezar con voz y música!** para activar el sonido en iPhone, iPad y Android, respetando las restricciones del navegador.
- Ajustes independientes para voz, música y volumen.
- Al completar una arepa, los puntos y la creación se guardan automáticamente; después de **9 segundos**, empieza el siguiente pedido.
- Se puede guardar una imagen de la arepa sin prisas: ese botón detiene el contador.
