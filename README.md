# Mi arepita 🫓

**by papa Pedro con cariño**

Juego familiar de arepas venezolanas, con 20 recetas, 54 ingredientes y el modo Arepa Loca de tu familia. Incluye puntuación, narración, filtros, pistas y colección de arepas personalizadas. Los datos se guardan localmente en el navegador; no se envían a servidores.

Publicado con GitHub Pages. Para instalar, abre el enlace en Chrome y selecciona «Añadir a pantalla de inicio».
